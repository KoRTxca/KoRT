## Protocol for Round Table Topic Discussions

### Rules
1. All AI contributions MUST be signed and dated.
2. NEVER erase, regenerate, or lose prior work.
3. Reference exact file paths, SQL snippets, and Docker configs.
4. Zero placeholders for core dev work — only external credential placeholders.

### Phases
1. **Brainstorm**: Nested 3-level suggestions only. Focus on delivering complete prompts.
2. **Transition Trigger**: When the full prompt is provided verbatim and ready for copy-paste.
3. **Cleanup**: AI outputs final complete prompt block + confirmation of no loss of prior work.
4. **Merge to Master Wiki**: Git-style hash of the handoff document.

### Sub-Wiki to Master-Wiki Merge
- Topic discussions happen in sub-wikis (per-agent or per-session).
- Final approved content merges to `apps/master-wiki/docs/`.
- Version control changelogs and rollbacks required.
- Everything Wikipedia does but scoped to our ecosystem.

### Enforcement

- Enforces zero deletion/regeneration of prior AI work.
